# v0.1.5

This patch fixes automatic GPU bundle installation and release publication.
It includes prebuilt Transformer Engine PyTorch and DeepSpeed runtime wheels,
avoiding source builds and isolated PyTorch ABI mismatches. Transformer Engine
loads the cuDNN libraries from the installed NVIDIA wheel automatically.

- Replace same-version portable and native wheels while resolving GPU dependencies.
- Explain missing release catalogs with the exact URL and source-build path.
- Check a clean, binary-only installation and native library loading on CPU.
- Qualify the Ubuntu 24.04 / CPython 3.12 / Linux x86_64 / PyTorch 2.10 CUDA 12.8 /
  SM90 bundle on two H100 GPUs before publishing PyPI or GitHub assets.
- Include source revisions, SHA-256 checksums, SBOMs, qualification reports,
  and GitHub build attestations. Resume interrupted asset uploads safely.

Upgrade an existing v0.1.1 installation first:

```bash
python -m pip install --upgrade "turbo-dllm==0.1.5"
dllm bundle install --release v0.1.5 --auto
dllm doctor --training
```

Other Python, CUDA, and GPU combinations require a separately qualified
bundle or a source build. DeepSpeed optional native operators are not prebuilt.
See [GPU bundles](../operations/gpu-bundles.md).
