# v0.1.3

This patch fixes automatic GPU bundle installation and release publication.
The v0.1.2 tag was not published because GitHub rejected its reusable
workflow permission ceiling; v0.1.3 corrects that ceiling while keeping
qualification jobs read-only.

- Replace the portable wheel and coordinated native wheels even when their
  versions are already installed, while preserving dependency resolution.
- Explain missing release catalogs with the exact URL and source-build path.
- Qualify the CPython 3.12 / Linux x86_64 / PyTorch CUDA 12.8 / SM90 bundle
  on two H100 GPUs before publishing either PyPI or GitHub release assets.
- Include source revisions, SHA-256 checksums, SBOMs, qualification reports,
  and GitHub build attestations. Resume interrupted asset uploads safely.

Upgrade an existing v0.1.1 installation first:

```bash
python -m pip install --upgrade "turbo-dllm==0.1.3"
dllm bundle install --release v0.1.3 --auto
dllm doctor --training
```

Other Python, CUDA, and GPU combinations require a separately qualified
bundle or a source build. See [GPU bundles](../operations/gpu-bundles.md).
