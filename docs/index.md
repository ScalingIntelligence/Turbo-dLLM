# Documentation

Start with [installation](getting-started/installation.md) and the
[quickstart](getting-started/quickstart.md). Configuration, model, parallelism,
operations, API, development, and release-notes sections describe stable public
interfaces and supported behavior.

For speculative draft training, follow
[train and serve DFlash2](getting-started/dflash2-training-and-serving.md).

Use [data preparation](configuration/data-preparation.md) to compile Hugging
Face, JSONL, Parquet, text, or pretokenized records into the optimized runtime
formats before training.
