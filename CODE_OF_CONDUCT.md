# Code of Conduct

We want participation in Turbo-dLLM to be safe, respectful, and productive.

Contributors must communicate constructively, respect differing experience and
viewpoints, accept technical feedback in good faith, and avoid harassment,
threats, discrimination, sexualized conduct, or publication of private
information. These expectations apply in project repositories, issue trackers,
reviews, chats, events, and when representing the project elsewhere.

Report conduct concerns privately through the repository maintainers' GitHub
profiles. Maintainers will limit disclosure, investigate promptly, and may
edit, reject, remove, temporarily restrict, or permanently ban participation
when necessary. Retaliation against a reporter is prohibited.

Enforcement decisions should consider impact, recurrence, intent, willingness
to repair harm, and the safety of the community. Good-faith disagreement over
technical decisions is not misconduct.
